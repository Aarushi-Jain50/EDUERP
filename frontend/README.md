# EduERP Frontend Application

The EduERP frontend application is built using **Angular 21**, **TypeScript**, and **Tailwind CSS v4** with a clean, responsive admin dashboard layout.

## Key Technical Features

- **Zoneless Change Detection**: High-performance Angular zoneless architecture using Signals.
- **Shared UI Component Library**: Standardized page headers, stat strips, filter toolbars, data tables, right-side form drawers, and confirmation dialogs.
- **In-Memory State Management**: Typed Signal-based services for instant data updates across all ERP modules.
- **Role-Based Access Control**: User management and permission matrix interface.

## Directory Structure

```text
/src/app
  /components/shared   <-- Reusable UI Components
  /models              <-- TypeScript Interfaces & Models
  /services            <-- Signal State Services
  /pages               <-- Module View Components
```
