# EduERP Module Routes Map

| Module Route | Feature Description |
| :--- | :--- |
| `/admin/academic-years` | Manage academic calendar sessions (2025-26, status checks) |
| `/admin/departments` | Manage academic departments, HODs, student/faculty metrics |
| `/admin/courses` | Degree programs (UG/PG), duration, semesters, intake capacity |
| `/admin/semesters` | Semester duration & course mapping |
| `/admin/sections-batches` | Class sections (A/B) and student batch allocations |
| `/admin/subjects` | Course subjects (Theory / Practical / Elective) & credits |
| `/admin/subject-allocation` | Faculty subject assignment and weekly hours |
| `/admin/students` | Student profiles, enrollment numbers, contact details |
| `/admin/student-admissions` | Admission pipeline & status tracking |
| `/admin/faculty` | Faculty staff directory, designations, qualifications |
| `/admin/parents` | Parent/guardian records linked to students |
| `/admin/user-accounts` | System user credentials, usernames, profile linkage |
| `/admin/roles-permissions` | Role-based module permissions matrix |
| `/admin/recent-activity` | Real-time audit log of campus actions |
