# EduERP Shared UI Component Catalog

All admin pages strictly consume these shared component primitives to ensure 100% design consistency across all modules:

1. **`page-header`**: Standardized page title, subtitle, and Aurora-gradient primary action button.
2. **`stat-strip`**: 3-card summary metric strip with status indicator icons.
3. **`data-toolbar`**: Search bar (with minimum 40px height) + up to 2 filter dropdowns.
4. **`data-table`**: Compact 44px data rows, sticky headers, avatar/badge renderers, custom 3-dot action menu, and client-side pagination.
5. **`form-drawer`**: 420px/560px right-side slide-in panel with sectioned forms and validation error alerts.
6. **`confirm-dialog`**: Accessible confirmation modal dialog for delete operations.
