# EduERP Role-Based Access Control (RBAC) Matrix

System Roles:
1. **Super Admin**: Full unrestricted access to all modules and permission overrides.
2. **Admin**: Operational access for academics, student management, and reports.
3. **Faculty**: Access for marking attendance, entering marks, and syllabus management.
4. **Student**: Access to self-service portal for grades, attendance, fee receipts.
5. **Parent**: Access to student progress and fee payment portal.
6. **Accounts Officer**: Access to fee structures, payment ledgers, and collection reports.

## Module Scope

- Academic Management (Academic Years, Departments, Courses, Semesters, Sections, Subjects, Subject Allocation)
- People Management (Students, Admissions, Faculty, Parents)
- User & Security (User Accounts, Roles & Permissions)
