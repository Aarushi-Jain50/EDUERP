# EduERP Developer Setup & Contribution Guide

## Prerequisites

- Node.js >= 20.x
- npm >= 10.x
- Angular CLI >= 21.x

## Development Environment Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Run linting & build verification:
   ```bash
   npm run lint
   npm run build
   ```
